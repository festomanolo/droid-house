# 🏠 Droid House

> **A High-Performance, Premium ADB File Explorer for macOS.**

Droid House is a powerful, "Apple-native" file manager for Android devices. Designed for speed, aesthetics, and reliability, it transforms the clunky ADB experience into a fluid, "Speed of Light" workflow.

## 🚀 Key Features

### ⚡️ Speed of Light Previews
Our custom-built **Thumbnail Engine** eliminates the slow "copy-before-preview" workflow. 
- **exec-out Streaming**: High-speed binary streaming directly from your device.
- **Background Generation**: Thumbnails for photos and videos are generated while you browse.
- **Persistent Cache**: Instant reloading for previously visited folders.

### 🍱 Magnetic Interface
A deeply integrated macOS experience using native SwiftUI components.
- **Magnetic Inspector**: A smart right-sidebar that docks perfectly to your window.
- **Safari-style Navigation**: Fluid tab switching between your device and active transfers.
- **Dynamic Island Transfers**: Real-time progress pills that elegantly track your file operations.

### 🛜 Wireless Freedom
Connect to your device over Wi-Fi with one click.
- **Auto-Detection**: The app pings your network for available ADB devices.
- **Persistent Connectivity**: Stay connected even when the cable is gone.

### 📊 Insightful Storage
Real-time storage gauges for internal and external partitions.
- **Live Updates**: See exactly how much space is left as you manage files.
- **Detailed Stats**: Hover or glance for precise byte counts.

## 🛠 Setup & Requirements

1. **ADB Installed**: Ensure you have `adb` installed (via Homebrew: `brew install --cask android-platform-tools`).
2. **Developer Options**: Enable "USB Debugging" on your Android device.
